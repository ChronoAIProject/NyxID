# Reporting security vulnerabilities

Please report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/ChronoAIProject/NyxID/security/advisories/new). Do not post exploit details, credentials, or personal data in public issues. Private reporting was confirmed enabled during the 2026-10-19 assessment.

Include the affected version/commit, deployment type, prerequisites, impact, and minimal reproduction steps. Use test accounts and redact secrets. Describe any evidence shared elsewhere. Avoid testing against other people's accounts or production data without authorization.

## Response and supported versions

Maintainers have not published an acknowledgement deadline, resolution SLA, or supported-version matrix. This policy does not promise one. Include your installed version even if it is older than the latest release; maintainers can determine applicability and remediation when triaging the report. A release's availability alone does not establish ongoing security support.

## Technical documentation

See [the security architecture and operator guidance](docs/SECURITY.md) and [the W1–W4 remediation tracker](docs/SECURITY_REMEDIATION_W1_W4.md) for implemented controls and known work. Architecture descriptions are not a guarantee about a particular hosted deployment.
