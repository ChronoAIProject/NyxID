# Native integration verification — 2026-11-14 (#1868, Workstream 3)

## Environment and revisions

- Code under test: branch `feat/mobile-native-adaptation`, mobile at `fecd9defa`, backend at `fedbc84c0` (no backend changes after it), based on `main` `032777752`.
- iOS: Xcode 27.2, iOS 27.2 simulator (iPhone 18 Pro), Release configuration with the JavaScript bundle embedded, ad-hoc signing (`CODE_SIGN_IDENTITY=-`). The simulator build carried a local-only UIScene startup patch because `main` does not launch on the iOS 27.2 simulator without scene adoption; that patch is not part of this branch.
- Backend: local `nyxid-server` (`ENVIRONMENT=development`) on MongoDB 8.0; `nyxid node` 0.78.0 registered to it; OpenSSH target (Alpine 3.20, OpenSSH 9.7p1) trusting the service CA through `TrustedUserCAKeys` and `AuthorizedPrincipalsFile`.
- Service OAuth used a local mock OAuth 2.0 provider (HTTPS authorize page trusted by the simulator, Approve/Deny/Provider-error choices) registered through `nyxid admin catalog apply`.
- Android: no Android emulator or device was available, so no Android path was verified on a device. Android behaviour is covered by unit tests only.
