# Verdict

Scope: these verdicts are pinned to immutable commit `77c739cf`; uncommitted edits that appeared in the shared worktree during this pass are not part of the reviewed diff.

1. **PARTIALLY FIXED - live/history divergence.** Normal `TEXT_MESSAGE_END` completion is fixed: history and `closeOpenMessage` both call `textToBlocks`, whose canonical IDs/order cover marker-first, marker-last, marker-only, text/card/text, adjacent-marker, and no-marker shapes (`frontend/src/lib/assistant/aevatar-transport.ts:402`, `frontend/src/lib/assistant/aevatar-transport.ts:460`, `frontend/src/lib/assistant/aevatar-transport.ts:2270`). Client Stop is not fixed: `cancelTurn` completes only the already-open text block and never calls the projection, so cancelling after a complete marker emits no card (`frontend/src/lib/assistant/aevatar-transport.ts:2445`).
2. **PARTIALLY FIXED - `renderableText` monotonicity.** Column-indented markers are now rejected and canonical markers remain monotonic across CRLF, lone CR, tiny chunks, empty deltas, surrogate-pair boundaries, and long suffixes, but the accepted opener grammar permits spaces/tabs after the backticks while the prefix guard recognizes only the no-whitespace literal (`frontend/src/lib/assistant/connect-fence.ts:35`, `frontend/src/lib/assistant/connect-fence.ts:41`, `frontend/src/lib/assistant/connect-fence.ts:237`).
3. **PARTIALLY FIXED - fence state machine.** Matching delimiter character/length correctly protects column-zero tilde fences, 4+ backtick fences with inner triples, and mixed delimiters (`frontend/src/lib/assistant/connect-fence.ts:138`). It still misses valid Markdown fences indented one to three spaces because `FENCE_OPEN` is hard-anchored at column zero, and assistant-role filtering provides no provenance against a raw column-zero tool/model echo (`frontend/src/lib/assistant/connect-fence.ts:37`, `frontend/src/lib/assistant/aevatar-transport.ts:456`).
4. **FIXED - OAuth convergence and polling.** Terminal `active`/`failed` data makes `refetchInterval` return `false`, and the effect invalidates the exact `['keys']` list query consumed by `useKeys` (`frontend/src/hooks/use-keys.ts:17`, `frontend/src/hooks/use-keys.ts:70`, `frontend/src/hooks/use-keys.ts:85`). `queryClient` is stable and `status` is scalar, so StrictMode may duplicate a terminal invalidation in development but cannot create an effect loop (`frontend/src/hooks/use-keys.ts:84`). The code is correct despite the missing hook test.
5. **FIXED - duplicate placeholder.** `authorizing` is derived from the existing `pending_auth` row and is explicitly excluded from the action render condition, so the second Connect button is gone (`frontend/src/components/assistant/blocks/connect-card.tsx:94`, `frontend/src/components/assistant/blocks/connect-card.tsx:153`).
6. **PARTIALLY FIXED - catalog 404 versus retryable failures.** The 404/other-error classification and retryable copy are correct, and withholding only a fresh connect while catalog data is pending is sound because the dialog independently requires a resolved catalog entry before creation (`frontend/src/components/assistant/blocks/connect-card.tsx:55`, `frontend/src/components/assistant/blocks/connect-card.tsx:122`, `frontend/src/components/dashboard/add-key-dialog.tsx:2480`, `frontend/src/components/dashboard/add-key-dialog.tsx:2570`). However, the unconditional `unresolvableSlug` render guard also hides an existing row's catalog-independent **Manage** action on a 404, contradicting the stated exception (`frontend/src/components/assistant/blocks/connect-card.tsx:109`, `frontend/src/components/assistant/blocks/connect-card.tsx:153`, `frontend/src/components/assistant/blocks/connect-card.tsx:159`).
7. **PARTIALLY FIXED - marker-free byte identity.** `"Hello "` now retains its trailing space and ordinary backtick-leading prose is released as soon as it stops being a viable marker prefix (`frontend/src/lib/assistant/connect-fence.ts:237`, `frontend/src/lib/assistant/connect-fence.ts:250`). The broader byte-identity claim remains false: live projection normalizes every `\r` and strips terminal newlines before emitting deltas, although normal completion later replaces a marker-free block with the raw source (`frontend/src/lib/assistant/connect-fence.ts:72`, `frontend/src/lib/assistant/connect-fence.ts:253`, `frontend/src/lib/assistant/aevatar-transport.ts:403`).

# New defects introduced by the fixes

1. **MAJOR - an accepted marker form still makes the streamed projection shrink.** Concrete deltas: first `"Before\n``` nyxid:connec"`, then `"t"`. The first projection includes the partial marker text; the second suddenly recognizes a pending marker and returns only `"Before"`. The transport then refuses the shorter value and retains a stale suffix offset (`frontend/src/lib/assistant/connect-fence.ts:35`, `frontend/src/lib/assistant/connect-fence.ts:237`, `frontend/src/lib/assistant/aevatar-transport.ts:1505`). The same failure exists with a tab after the backticks.
2. **MAJOR - a visually valid indented outer fence can still mint an actionable card.** Concrete input: `" ```markdown\n```nyxid:connect\n{\"catalog_slug\":\"api-github\"}\n```\n ```"`. Markdown permits the outer fence's one-space indentation, but the parser misses that opener and consumes the inner marker (`frontend/src/lib/assistant/connect-fence.ts:37`, `frontend/src/lib/assistant/connect-fence.ts:156`). A raw, unfenced column-zero tool echo is likewise indistinguishable from the intended transport marker; the implementation relies on, but does not enforce, the Aevatar-authored-only premise (`frontend/src/lib/assistant/connect-fence.ts:13`, `frontend/src/lib/assistant/aevatar-transport.ts:456`).
3. **MINOR - newline normalization changes non-marker content in marker-bearing messages.** Concrete input `"```text\nA\rB\n```\n<valid connect marker>"` projects the ordinary code block as `"```text\nA\nB\n```"`; `normalizeNewlines` is applied to the entire message before segmentation, not only while comparing fence syntax (`frontend/src/lib/assistant/connect-fence.ts:72`, `frontend/src/lib/assistant/connect-fence.ts:121`). Malformed marker text can also be rewritten because every rejected closer is reconstructed as exactly three backticks rather than preserving the matched line (`frontend/src/lib/assistant/connect-fence.ts:161`, `frontend/src/lib/assistant/connect-fence.ts:184`).
4. **MINOR - the canonical empty leading text block creates visible layout spacing.** Marker-first and marker-only messages always receive an empty text block before the card (`frontend/src/lib/assistant/aevatar-transport.ts:413`). The renderer wraps every block and applies `space-y-3` to the block list, so the empty wrapper still causes a gap before the card (`frontend/src/components/assistant/chat-thread.tsx:259`, `frontend/src/components/assistant/chat-thread.tsx:267`, `frontend/src/components/assistant/blocks/text-block.tsx:143`).
5. **MINOR - a catalog 404 removes recovery for an existing manageable key.** Concrete state: an `NYXID_UNAUTHORIZED` card, a matching non-OAuth user key, and `/catalog/{slug}` returning 404. The code derives `actionLabel = "Manage"` and has a direct `/keys/{id}` navigation path, but the outer `!unresolvableSlug` condition prevents that button from rendering (`frontend/src/components/assistant/blocks/connect-card.tsx:109`, `frontend/src/components/assistant/blocks/connect-card.tsx:153`, `frontend/src/components/assistant/blocks/connect-card.tsx:159`).

# Remaining risk

- The committed convergence test does feed every case as **one** delta, exactly the weaker condition called out in the review request (`frontend/src/lib/assistant/aevatar-transport.test.ts:2765`, `frontend/src/lib/assistant/aevatar-transport.test.ts:2772`). It also constructs `liveBlocks` from `block.completed` events instead of applying all events through the production reducer, so it does not prove that start indices/message IDs produce the same reducer state (`frontend/src/lib/assistant/aevatar-transport.test.ts:2782`, `frontend/src/lib/assistant/stream.ts:122`). Do not treat it as proof of multi-delta or Stop convergence.
- The monotonic property test is useful, not a tautology, but its sample table omits every accepted whitespace-bearing marker opener, so the grammar mismatch above is outside its exhaustive-prefix loop (`frontend/src/lib/assistant/connect-fence.test.ts:218`, `frontend/src/lib/assistant/connect-fence.test.ts:230`). Add canonical plus interstitial/trailing space/tab variants, CRLF and lone-CR variants, empty deltas, code-unit splits through emoji, and long post-marker suffixes (`frontend/src/lib/assistant/connect-fence.test.ts:234`).
- Fence tests cover a plain triple fence and one four-backtick example, but not tilde fences, mixed delimiters, one-to-three-space ordinary fence openers, indented code blocks, or a genuine marker after each legal close (`frontend/src/lib/assistant/connect-fence.test.ts:71`, `frontend/src/lib/assistant/connect-fence.test.ts:102`). Do not assume quoted/tool-echo safety is proven.
- `useKeyAuthorizationStatus` has no committed test at all; the hook is absent from the test file's import list (`frontend/src/hooks/use-keys.test.tsx:5`). Add a shared-`QueryClient` StrictMode test with fake timers that observes `pending_auth -> active` and `pending_auth -> failed`, asserts no further `/keys/{id}` calls after multiple 2-second advances, asserts an active exact `['keys']` list refetches, and asserts invalidation does not refetch the detail query (`frontend/src/hooks/use-keys.ts:60`, `frontend/src/hooks/use-keys.ts:70`, `frontend/src/hooks/use-keys.ts:85`).
- Dialog tests mock the polling hook and prove only the dialog's terminal copy; they do not exercise the interval or list-cache convergence that the transcript card depends on (`frontend/src/components/dashboard/add-key-dialog.test.tsx:579`, `frontend/src/components/dashboard/add-key-dialog.test.tsx:599`).
- The upstream producer is still listed as remaining work and must guarantee programmatic marker authorship/escaping; frontend assistant-role checks alone cannot distinguish an intended marker from exact marker-shaped assistant/tool text (`docs/ASSISTANT_IN_CHAT_CONNECT_PLAN.md:243`, `frontend/src/lib/assistant/aevatar-transport.ts:456`).
