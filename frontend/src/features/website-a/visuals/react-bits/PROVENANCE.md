# React Bits 来源与原生适配 / React Bits source and native adapters

四个实际组件来自已批准评审材料，固定上游 commit：`496968c4117e21278f13917201b7d615bc5e7450`，仓库 [DavidHDev/react-bits](https://github.com/DavidHDev/react-bits/tree/496968c4117e21278f13917201b7d615bc5e7450)。上游路径分别为 `src/ts-default/TextAnimations/GradientText/`、`src/ts-default/Components/SpecularButton/`、`src/ts-default/Components/SpotlightCard/` 与 `src/ts-default/Animations/FadeContent/`。

The four actual components come from the approved review sources at the pinned upstream commit above, under the corresponding TypeScript default paths. The review's exact input hashes are recorded in `upstream-hashes.json`; no runtime fetch of review HTML or component source is used.

完整许可保存在 [LICENSE.md](LICENSE.md)：**MIT + Commons Clause License Condition v1.0**，不是纯 MIT。GradientText、SpecularButton、SpotlightCard、FadeContent 是实际代码基础，未以同名 CSS 效果替代。DriftWall 未复制、导入或打包。GSAP 作为正式依赖锁定到评审使用的 `3.15.0`，其许可随 npm 包保留。

The complete MIT + Commons Clause license is retained, including its conditions. These are source integrations rather than similarly named CSS substitutes. DriftWall is excluded. The actual FadeContent animation uses GSAP 3.15.0, with its package license retained by the dependency.

| Component      | Production adaptation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GradientText   | Original gradient algorithm and nine-second brand parameters; update imperative settings after render for React compatibility. Shared activity gate unmounts animation offscreen/background/reduced motion; static title remains. The approved dark palette is independent of application/system theme preferences.                                                                                                                                                                                                                                                      |
| SpecularButton | Retains reviewed native-anchor target mode and shader algorithm. An effect owns a fresh canvas on each setup, preventing StrictMode replay from reusing a context lost by cleanup. Release shaders/program/buffer/VAO/context and remove the canvas; stop after context loss; hide failed canvases so CTA text is never covered. Partial failures retain the original anchor. Read-only canvas diagnostics expose renderer readiness and the same light level/position sent to shader uniforms. Add explicit types for strict indexed access. |
| SpotlightCard  | Its light/edge/grain algorithm observes and receives pointer/focus events from the actual existing anchor through `target`, with no extra Tab stop. Its theme follows the independent dark website design. A pointer-transparent decorative layer keeps the original layout. Update settings after render; shared gate unmounts it when inactive or a filtered link is hidden.                                                                                                                                                                                                                       |
| FadeContent    | Preserve the GSAP set/timeline/ease animation core. Native `target` plus the shared IntersectionObserver gate replaces prototype ScrollTrigger wiring. Pause/resume the same one-time timeline on foreground/visibility changes; `.08` is supplied to the frame observer. Initial opacity `.72`, duration `600ms`, no blur. Default DOM is visible; reduced motion and cleanup restore original inline styles. No extra wrapper is inserted into the layout.                                                                                  |

原型的全局 `wire` 覆盖、多 React root、MutationObserver 重建与 DOM 标题替换未移植。正式生成器输出 `VisualLink`、`RevealFrame`、`HeroSection` 和 `HeroTitle`，最终仍为原生 `<a>`、`<div>`、`<section>`、`<h1>`；样式和新增状态仅限官网 `.website-a`。V01 的运行时 URL/scene ID 可由 `VITE_WEBSITE_BACKGROUND_RUNTIME_URL` / `VITE_WEBSITE_BACKGROUND_PROJECT_ID` 配置，默认复用原 v2.1.4 场景；`VITE_WEBSITE_VISUALS_ENABLED=false` 为整体静态回退。

The prototype's global DOM rewiring, extra React roots, mutation-driven redecorating and title replacement are not shipped. Native React elements preserve existing links and handlers. All new CSS is website-scoped. Background configuration defaults to the existing v2.1.4 scene; a build-time visual flag supports a static rollback.

组件/装饰失败时保留内容和真实入口。诊断使用 `[nyxid-visual-v4]` 固定标识，不包含账号、凭据或请求数据。本实现不修改 Auth/OAuth/MFA、后端或计费。

Failures retain readable content and real navigation. Diagnostics use a fixed non-sensitive label and never account/credential/request data. Authentication, backend and billing are outside this implementation.
