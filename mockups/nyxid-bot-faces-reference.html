Face kit

Every bot NyxID creates gets a face from one small kit. The face is picked from the bot's id, so it never changes, never needs an upload, and two bots rarely match.

The kit

4 heads × 6 eyes × 6 colours = 144 faces. Every head keeps two marks from the NyxID logo: a notch in the top edge cut at the logo's 60° angle, and square corners on the left with round corners on the right. Nothing sits on top of the head, so the outline stays clean at every size.

How it is built







  
Colour

  
The same faces in eleven treatments. Pick a colour set to swap all seven columns. Only the first row of the Core set is what the app shows today; the rest suit bigger places such as profile photos, agent pages and empty states.

  

  

  

  
Gradient palette

  
35 gradient pairs in five sets. Core replaces today's flat tints one for one. Red stays out of every set so a bot never looks like an error.

  






  
Dither

  
A light falls on the face from the top left, and the shading is turned into a small set of pixel colours. Nine ways to do that, from print halftone to an old handheld screen.

  






  
ASCII

  
The same shading written as characters. Each character sits in a fixed grid cell, so the face keeps its shape whatever the font.

  






  
Motion

  
Each motion is tied to something a bot is doing, so it carries meaning instead of decoration. Everything holds still when the viewer has reduced motion turned on.

  

  
Halftone ripple as a background

  
The ripple also works behind a face: on an agent page header while the bot is listening, or as a tile background. The face itself stays flat and sharp on top, so it reads at any size.
